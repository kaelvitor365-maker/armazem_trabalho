# MAKEFILE

## COMANDOS

os comandos são:

|comando|descrição|
|-------|---------|
|`make install`| utilizado para configurar o ambiente antes de executar|
|`make run`| utilizado para rodar o codigo|
|`make clean`| nescessario caso queira limpar o cache que foi rodado|
|`make reinstall`| este comando limpa e re-instala todas as dependências|
|`make help`| mostra os comandos existentes|
